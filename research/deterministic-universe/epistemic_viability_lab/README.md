# Epistemic Viability Lab

Exploratory **reproducible** work on deterministic partially observed worlds: can an immediately informative but physically safe action destroy the opportunity for future safe identification?

**Status:** illustrative construction; no novelty or real-world safety guarantee claimed. 2026-11-04.

## Reproduce

```bash
python experiment.py
```

No third-party dependencies. The program enumerates **all 734 reachable belief states** of a known finite model containing 64 candidate deterministic laws, computes the strong-reachability layers, solves the expected information problem over finite horizons, and validates identification in all 64 worlds.

Main results:

- Greedy immediate information gain: take an irreversible snapshot, learn 2 of 6 hidden bits and get stuck forever.
- Horizon-aware safe identification: prepare a probe first, then test 6 bits. Full identification in exactly 7 actions, confirmed for all models.
- 730 of 734 beliefs permit eventual full identification; 4 sealed beliefs do not.
- Goal-relative check: snapshot is optimal in one step if only its two revealed bits matter; it is a dead end if one of the hidden remaining bits is essential.

See [research_note.md](research_note.md) for precise mathematics, proof, modeling assumptions, prior art, and limitations. CSV files are generated by the code and provided as convenience.
